# Basavaraj H G - Portfolio (Full Stack Developer)

Static site, no build step.

- index.html  page markup and all text content
- styles.css  styling (colors are CSS variables at the top of :root)
- script.js   behaviour: nav highlight, lanyard ID card physics, skills table, projects tabs, learning list, journey tabs, counters
- assets/     hero-cutout.webp (hero photo), id-photo.jpg (ID card photo)

Run: open index.html in a browser (or `npx serve .`).
Deploy: drag the folder onto Vercel or Netlify, or push to GitHub Pages.
